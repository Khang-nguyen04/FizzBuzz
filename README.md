# FizzBuzz

## What is this project?

This project is a small Java program that prints a list of values from 1 through 100. Each value appears on its own line, so the output is easy to read from top to bottom.

Most of the time, the program prints the number itself. Some numbers are replaced with special words based on whether they are **divisible by** 3, 5, or both.

**Divisible by** means one number can be divided by another number with nothing left over. For example, 6 is divisible by 3 because 6 divided by 3 equals 2 exactly. But 7 is not divisible by 3 because there is 1 left over.

The rules are:

- Print **FizzBuzz** if the number is divisible by both 3 and 5.
- Print **Fizz** if the number is divisible by 3.
- Print **Buzz** if the number is divisible by 5.
- Otherwise, print the number itself.

Here is a short sample of the expected output:

```text
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```
